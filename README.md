# Capstone_Pizzaria_Application

# 🍕 Pizzeria App

A responsive React-based Pizzeria application where users can browse pizzas, add them to the cart, customize ingredients, place orders, and submit feedback.

---

# 🚀 Features

- User Registration
- User Login
- Protected Routes
- Browse Pizza Menu
- Add Pizza to Cart
- Increase / Decrease Quantity
- Customize Pizza Ingredients
- Dynamic Price Calculation
- Checkout Page
- Order Success Page
- Feedback Form
- LocalStorage Support
- Redux Toolkit State Management
- Responsive Design

---

# 🛠 Tech Stack

- React
- Vite
- React Router DOM
- Redux Toolkit
- React Redux
- CSS3
- LocalStorage

# ⚙ Installation

Clone the repository

```bash
git clone <repository-url>
```

Go inside project

```bash
cd pizzariaapp
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```
